# Synthetic demo outputs

`investor_pitch.pptx` is a **native-editable, brand-neutral, editorial** 13-slide illustration generated from `examples/sample_deck.json` and the fictional `examples/sample_b2b.json` business.

- `investor_pitch.pdf` — PDF preview of the actual deck (not a moodboard).
- `contact-sheet.png` — montage of the actual rendered slides.
- `financial_model.xlsx` — formula-driven demo model with editable inputs (requires artifact_tool to rebuild).
- `metrics.json`, `monthly.json`, `market.json` — one numerical source of truth.
- `deck_manifest.json` — KPI and chart data binding checks.

All market figures, claims, taxes and forecasts are synthetic. The demo exists to validate editable PPTX generation, not to simulate a real company.

Slide 9 contains the native-editable Unit Economics spread (LTV/CAC, CAC, contribution LTV, margins, retention).
