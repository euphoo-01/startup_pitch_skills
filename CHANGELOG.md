# Changelog

## 2.1.0 — 2026-11-14
- Added automatic editable Unit Economics KPI slide for single-stream subscription businesses: **LTV/CAC, CAC, contribution LTV, Gross Margin, Contribution Margin, retention**.
- Increased grotesque typography emphasis using Inter Display for headings and key figures; reduced generic sample copy.
- Strengthened PPTX audit: KPI values now revalidated against source metrics, including market values; altered financial assumptions make a stale slide fail audit.
- Updated demo, slide preview and tests (13 slides, 17 automated tests).

- Kept native editable PowerPoint objects and existing deterministic business-finance v1 core.
