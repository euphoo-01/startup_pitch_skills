# Быстрый запуск Business Analyst + Investor Slides

## 1. Создать GitHub-репозиторий

Распакуй архив и загрузи **содержимое папки `investment-skillkit`** в новый репозиторий. В корне должны находиться `README.md`, `install.py`, `package.json` и папка `skills/`. Не нужно загружать `.zip` как единственный файл репозитория.

## 2. Установить

```bash
npm install
python install.py --target all --project /путь/к/проекту
```

`--target all` копирует оба навыка в `.agents/skills/` и `.claude/skills/`. Для переустановки добавь `--force`. Если хочешь использовать навыки глобально, выбери `--scope user`.

## 3. Пример

```bash
python scripts/build_demo.py
```

Получишь редактируемый `demo/investor_pitch.pptx`, `demo/metrics.json`, `demo/monthly.json`, `demo/market.json`, `demo/deck_manifest.json`, а при доступных зависимостях — ещё Excel и PDF.

## 4. Настроить оформление

Измени `examples/sample_deck.json`:

```json
"theme": {"preset": "editorial-blue", "font": "Inter"}
```

Возможные палитры: `editorial-blue` (нейтральная), `graphite-lime`, `warm-coral`. Для реального проекта передай свои цвета. **Не надо копировать стиль Northline или «Зачёта».**

## 5. Запустить на своей идее

Напиши агенту:

> Используй skill `business-analyst`. Исследуй мою идею, задай только важные вопросы, проверь конкурентов и спрос, сделай сопоставимые PAM/TAM/SAM/SOM, юнит-экономику, налоги и финансирование на помесячном горизонте до 36 месяцев. Не утверждай инвестиционную готовность без подтверждённых источников. После согласования передай расчётные файлы в `investor-slides` и создай презентацию PowerPoint с редактируемыми объектами.

## 6. Проверка

```bash
python -m unittest discover -s tests -v
```

В презентациях автоматически проверяются связанные KPI и наличие нативных объектов. Дополнительно обязательна визуальная проверка PNG/PDF рендера.

**Ограничения:** реальные налоги нужно проверять по актуальному законодательству; движок является стартовой моделью, а не универсальной бухгалтерской системой.
